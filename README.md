# 圖片壓縮轉檔器 (Python Squoosh)

## 概述

**圖片壓縮轉檔器** 是一個基於 Python 的桌面應用程式，功能類似於 Squoosh。它提供直觀的圖形介面，讓使用者能夠輕鬆地壓縮圖片、轉換格式，並即時預覽壓縮前後的差異。支援拖放操作與網址載入，適合需要快速優化圖片的使用者。

## 主要功能

### 1. **圖片壓縮與轉檔** 🖼️
- **多格式支援**：支援常見圖片格式（如 JPEG, PNG, WEBP）的讀取與寫入。
- **僅轉檔模式**：新增「僅轉檔」選項，可將原圖直接轉換為目標格式而不進行額外壓縮（自動禁用品質調整）。
- **即時預覽**：提供分割視窗（Split View），透過滑桿即時比較原始圖片與壓縮後圖片的畫質差異。
- **參數調整**：可自訂壓縮品質、格式等參數，即時查看檔案大小變化。

### 2. **圖片編輯工具** 🛠️
- **縮放檢視**：支援圖片縮放功能，方便檢視細節。
- **裁切功能**：內建裁切，可針對特定區域進行處理。

### 3. **便捷操作** 🖱️
- **拖放支援**：直接將圖片檔案拖入視窗即可開啟（支援多檔拖入）。
- **網址載入**：支援輸入圖片 URL 直接下載並編輯。
- **批次處理**：支援多張圖片載入與切換處理。
- **剪貼簿支援**：支援 `Ctrl+V` 貼上圖片/檔案/網址，以及 `Ctrl+C` 複製處理後的圖片 (Windows)。

### 4. **檔案資訊** 📊
- **大小比較**：即時顯示原始檔案大小與壓縮後檔案大小。
- **格式資訊**：顯示圖片的原始格式與目標格式。

### 5. **浮水印 (Watermark)** 🔖
- **用途**：可在輸出檔案上加上文字或圖片浮水印，方便標示來源或版權資訊。
- **介面支援**：在 GUI 中提供浮水印設定，包含文字設定與圖片設定（可同時使用）、位置選擇（左上/右上/左下/右下/置中）、不透明度與字型大小調整。
- **僅轉檔模式相容性**：即使啟用「僅轉檔」模式，浮水印仍會在匯出時套用；若想保留原始檔案的未修改版本，請先備份原檔或在匯出時使用不同檔名。
- **支援格式**：對於常見的輸出格式（JPEG, PNG, WEBP）皆可套用文字浮水印；若使用透明背景（如 PNG），請注意浮水印的不透明度設定以免影響視覺效果。
- **示例使用情境**：
  - 在 UI 中輸入文字「© YourName」或選擇圖片，選擇右下角並將不透明度設為 0.6，匯出後檔案會包含該浮水印。
	- 批次處理多張圖片時，浮水印會依設定自動套用於每張輸出影像。
- **實作備註（開發者）**：在程式內可以於輸出流程中使用 Pillow 的繪圖功能（ImageDraw / ImageFont）將文字繪製至影像上。注意在處理字型、字級與非 ASCII 字元時，需指定可支援的字型檔（例如系統字型或專案內的 .ttf 檔案）。

## 使用方法

### 啟動應用
1. 確保已安裝 Python 環境。
2. 執行 `main.py` 啟動程式。
3. 將圖片拖入視窗、使用選單開啟檔案，或直接貼上剪貼簿內容。

### 開發與執行

#### 安裝依賴
```bash
pip install -r requirements.txt
```

#### 執行程式
```bash
python main.py
```

#### 執行單元測試
本專案包含完整的單元測試，確保核心邏輯的穩定性。
```bash
python -m unittest discover tests
```

## 技術棧

| 組件 | 說明 |
|------|------|
| **Python** | 3.x |
| **GUI 框架** | `tkinter` (標準庫) + `tkinterdnd2` (拖放支援) |
| **圖片處理** | `Pillow` (PIL Fork) |
| **網路請求** | `requests` (用於 URL 圖片載入) |
| **測試框架** | `unittest` (標準庫) |
